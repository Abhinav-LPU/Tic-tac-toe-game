# Tic-tac-toe-game
Python Tic-Tac-Toe (Tkinter GUI):
A lightweight, interactive Tic-Tac-Toe game built with a Graphical User Interface (GUI) using Python's standard tkinter library.

Features
1. Graphical Interface: Simple grid layout built entirely with Tkinter buttons.
2. Turn Tracking: Displays the current player's turn ("X" or "O") dynamically.
3. Win Validation: Checks all 8 possible winning combinations after every move.
4. Visual Highlights: Turns the winning row, column, or diagonal green upon victory.
5. Popup Alerts: Notifies players of the winner via a standard message box.

How to Run:
1. Make sure you have Python installed on your system (tkinter comes built-in).
2. Save the script into a file named tictactoe.py.
3. Launch the game from your terminal
